## Context

See proposal.md — Why. Bare windowed measures route through `classify_isolation` → `WindowedAggregatePlan` → the `_wm_` range-join CTE rooted on the host `_base` (`generator.py:3282`); bare first/last through `RANKED_HOST` → `RankedAggregatePlan` → the self-contained `_rk_` row_number CTE. The DEV-1824 regroup producers for `partition_by=`+`window=`/first-last already render through these same kernels nested inside the producer sub-plan (hoisted flat; ranked collapses to a single CTE for SQL Server). `_plan_regroups` groups producers per phase by `(regroup_root_grain, windowed-bool)`; the same aggregate in both roles plans two producers (D10) though the placeholder is interned cross-phase. DEV-1839 (assumed merged before implementation) supplies union-grain nesting: producer plans carrying their own combined attaches. Constraints: goldens byte-identical except individually approved batches; executed values never change; fail closed, never internal errors; cross-model untouched (stage 3).

## Goals / Non-Goals

**Goals:** one composition mechanism for all LOCAL measure families; consumer-level family wiring deleted; plan-time producer dedup; the DEV-1839 lift for windowed/first-last inner aggregates.

**Non-Goals:** cross-model families and target-rooted producers (DEV-1836); retiring `classify_isolation` dispatch entirely (DEV-1836); dissolving the producer-internal `WindowedAggregatePlan`/`RankedAggregatePlan` IR and the flat-residue node discipline (DEV-1838); windowed min/max/count (G1 stays); host-base sharing / structural CTE dedup across producer internals (perf cost accepted, recorded).

## Decisions

- **D1 — Plan-time desugar, measure/order/filter roles only.** A bare windowed/ranked aggregate is routed into regroup discovery as a combined-attach root whose producer grain is the full projected grain (windowed: projected dims + non-active buckets, active TD as the D5 synthesized bucket; ranked: every visible projected slot). The consumed `AggregateKey` keeps `partition_keys=None` — public naming and placeholder identity untouched. Bare aggregates in dimension expressions stay rejected (grain self-containment). *Rejected:* stamping the implicit partition onto the key — changes public aliases and key identity for no gain.
- **D2 — Option A deletion depth: kernels survive producer-internal.** The consumer-level wiring, plan fields' top-level use, `IsolationKind.WINDOWED`/`RANKED_HOST`, and `OrderScope.WINDOWED_CTE`/`RANKED_CTE` (+ their `OrderEnv` fields, an import-time-guarded pair) are deleted; the range-join and row_number builders remain what producer sub-plans render through. The skip/dispatch the deleted branches provided relocates into the planner loop ahead of the `partition_keys` assert. *Rejected:* rendering producers without the family plan classes — re-derives fought-for renderer behavior (DEV-1732 rewrites, empty-grain collapse, temporal-cast suppression) in one stage; that dissolution is DEV-1838's.
- **D3 — W1: uniformly self-contained producers; uniform `_cm_` naming; windowed collapse.** Bare and partitioned producers share one shape; a `_collapses_to_windowed_cte` mirror of the ranked collapse elides the redundant wrapper. Accepted costs: every bare-windowed golden diverges (own grain-rows relation instead of referencing `_base`; one extra source scan per windowed producer group, re-recorded in the perf corpus); ranked comes out near-identical modulo CTE name. *Rejected:* host-anchored producer bodies for byte-identity — reintroduces the host-rooted coupling being removed and forks the producer shape.
- **D4 — Producer synthesis from original expressions; nested LOCAL row attaches (Codex F2).** The producer prebound receives the original pre-substitution dimension expressions; the producer's own recursive `plan_query` runs its own regroup discovery, building internal row attaches naturally — substituted placeholders are never handed to a sub-plan lacking their definitions. The `stage_planner.py:1613-1621` fail-closed narrows to nested cross-model. A recursion-depth guard with a deterministic error backstops cycle arguments. The windowed `_src` subquery and ranked inner select render regroup-aware (env + join specs threaded, the stage-1a D3 pattern) — a raw source row must know its computed-dim value to group correctly.
- **D5 — Grain membership by slot provenance, never placeholder identity (Codex F1).** The desugar's grain inference classifies each projected slot via the attach records that reference it (`attach_phase` on substitutions) — a D10 dual-role placeholder that is a projected dimension slot IS a grain member. The `_host_grain` prefix-matching wart is replaced, not copied.
- **D6 — Plan-time dedup on canonical producer-spec equality (Codex F3).** The IR splits into a producer table (one per structural identity) + N attach records (phase, join pairs, substitutions) referencing producers. Identity = structural equality of the complete canonical producer prebound (grain keys, normalized partition-free consumed measures incl. `column_filter_key`, inherited filters, ranking/time context) — not a hand-picked tuple. Dual-phase producers use the combined-phase naming regime so row-only/combined-only queries keep their SQL. Effective grain replaces the `(grain, windowed-bool)` key: the windowed axis is the TD member of the grain. *Rejected:* render-time `_cm_plan_identity`-style dedup — leaves duplicate producers in the IR for stage 3 to keep handling.
- **D7 — Guard map.** G4/G5/G6/G7 + the post-projection twin and `time_shift`-over-ranked dissolve (the latter unreachable once ranked slots are placeholders — deleted). G1/G8/G2 and the ranked no-ranking-column error stay verbatim (G2 raised from the desugar path). G3 and the cross-model `partition_by` messages re-point DEV-1504/DEV-1824 → DEV-1836. The `change`/`change_pct`-over-attached internal error (composite-of-transform inputs not materialized as slots when over a placeholder) is fixed in scope, failing-first.
- **D8 — Filter routing is the existing pre-substitution machinery, stated and tested (Codex F4/F5).** Desugared references flow through `split_top_level_and` → `conjunct_scope` → explicit placement; filter-only references create hidden producers; mixed OR keeps the no-common-scope directive. Measure-local filters (`column_filter_key`) restrict producer rows only; query/model row filters duplicate into host and producer (the established ranked-planner rule, now uniform).
- **D9 — Time axis: effective grains; the synthesized bucket ≡ the consumer's bucketed TD.** Windowed effective grain = `partition_by ∪ {active bucket}`; first/last = `partition_by`. One `TimeTruncKey` identity unifies the bucket across union membership, dedup, and attach keys. Inside the producer the bucket is the temporal transforms' ordering axis; other members partition; rank is timeless. The residual DEV-1839 windowed/first-last guard is deleted last, as a separable task.
- **D10 — Test-surface protocol (user-approved).** Executed values are the invariant; golden divergences enumerated with before/after SQL → batch approval → re-bless; SQL-shape suites rewritten preserving intent; guard tests flip direction; classifier tests keep cross-model pins; perf corpus re-recorded with regressions reported. Both engines (SQLite + DuckDB) execute every migrated family and lifted cell, incl. NULL grain keys, keyless/CROSS JOIN, filtered, and order-only variants (Codex F6). Newly discovered deferrals: strict-xfail + a comment on the target issue.

## Risks / Trade-offs

- [Desugar changes values for an existing windowed/ranked shape] → bare-vs-explicit equivalence tests plus migrated-family executed-value pins on both engines; any value diff is a bug, never a re-bless.
- [Nested row attaches inside producers meet an unanticipated recursive shape] → synthesis from original expressions with a depth guard and deterministic error; band-derived-from-partitioned-window and shared-inner-aggregate tests.
- [Dedup merges producers that differ in an unmodeled input] → identity is whole-prebound structural equality; negative dedup tests for filter/window/ranking-arg differences.
- [Golden churn hides an unintended divergence] → divergences enumerated per shape with before/after SQL; nothing re-blessed without batch approval; `assert_scope_closed` + no-`__regroup__` on every new emission.
- [DEV-1839 lands with different interfaces than assumed] → the lift is the final separable task; the MODIFIED transform requirement is re-baselined against the post-1839 corpus at implementation start (`validate --strict` re-run).
- [Perf regression from self-contained windowed producers] → perf corpus re-recorded; regressions reported in the PR, not silently absorbed.

## Migration Plan

Single PR on this branch, tests-first (TDD): tests land before implementation; implementation proceeds desugar → producer generalization → deletion → dedup → guard dissolution → DEV-1839 lift, each guard removal in its own commit where practical (revertible without touching mechanics). Rollback = revert the PR (no storage/schema migrations). Post-merge: archive; re-point any residual issue refs.

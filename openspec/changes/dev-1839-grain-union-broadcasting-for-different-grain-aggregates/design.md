## Goals / Non-Goals

**Goals:** the union-grain lift for plain (incl. keyless) mixed-grain aggregates and nested transforms inside a transform-in-dimension; the recursive grain-union principle codified; bare composite measure arithmetic over partitioned aggregates lifted (D10); the temporal-axis containment guard (D9); locking coverage for already-conforming surfaces.

**Non-Goals:** mixed windowed/`first`/`last` grains (stage 2, DEV-1835 — union must include the D5 synthesized time bucket; time-axis question); cross-model inner sources (stage 3, DEV-1836); aggregate-over-attached-value nested attach; raw-column leaves inside a transform-in-dimension (stays illegal; clean grain-self-containment message only); union minimization (redundant functionally-dependent keys tolerated); attach dedup (stage 2 — duplicate producers per D10 accepted).

## Decisions

- **D1 — Union-grain root rule.** `regroup_root_grain` for a transform root returns the set-union of ALL grained inner aggregates' partition sets (any nesting depth, `walk_value_keys`); keyless contributes ∅. *Rejected:* per-branch grain inference — the union is the only grain at which every operand is defined without aggregation.
- **D2 — Recursive producer synthesis with own-grain exclusion as terminator (Codex F2 amended).** Inside a producer, discovery classifies roots exactly like the top level: a bare aggregate or transform root at exactly the producer's own grain compiles inline (grouped aggregate / step chain — byte-identical for today's single-grain shapes); a strict-subset bare aggregate becomes a nested combined attach; a strict-subset transform root becomes a nested combined attach whose producer is the transform-at-producer-grain shape applied recursively. Exclusion-by-own-grain terminates recursion structurally (grains strictly decrease; partition sets are finite). *Rejected:* Codex's key-rewrite lowering (strip `partition_keys` at the union grain) — same termination, but rewrites structural keys and threatens substitution identity and byte-identity.
- **D3 — Dedicated producer-planning control (Codex F1).** A new flag (e.g. `enable_producer_regroups`) turns on regroup discovery for producer plans while `disable_host_rooted_isolation` stays True — that flag also gates host-rooted isolation preprocessing (`stage_planner.py:1771`), which must remain off for synthesized producers. *Rejected:* flipping `disable_host_rooted_isolation` — changes unrelated behavior.
- **D4 — Structural validation of admitted nested plans (Codex F4).** Narrowing the `:1615` rejection to cross-model is insufficient; admitted producer plans are validated: local sources only, combined-phase attaches only, every nested grain a strict subset of the producer grain, no row attaches, no deeper regroups after the exclusion rule. Violations fail closed with a clear message.
- **D5 — Hoistable-producer render context (Codex F3).** Split "CTE body, WITH forbidden" (SQL Server nested-WITH restriction; `_collapses_to_ranked_cte`) from "producer body whose internal WITH will be hoisted". `_render_producer_split` renders under the hoistable context; the `generator.py:~1651` combined-attach guard keys only on the genuinely non-hoistable case. SQL Server emission covered by tests.
- **D6 — Deferral guard predicate order (Codex F6).** The new mixed-windowed/ranked guard first establishes >1 distinct effective grain, then checks families — single-grain windowed/`first`/`last` transform inputs (lifted in DEV-1824) are untouched, locked by tests.
- **D7 — Transform kwargs against the union (Codex F7).** Keyword references resolve against producer slots (the union grain); unresolvable keys surface the existing clean reference error, tested positively and negatively.
- **D8 — Plan-structure assertion in acceptance tests (Codex F8).** The main acceptance test asserts one union-grain row attach whose producer carries the expected strict-subset combined attach(es), so a degenerate all-at-union implementation cannot pass on lucky data.
- **D9 — Temporal-axis containment guard.** A time-ordered transform (`cumsum`, `lag`, `lead`, `time_shift`, `change`, `change_pct`, `consecutive_periods`) inside a dimension SHALL have its resolved time-ordering key inside its evaluation grain (the union), else fail closed directing the author to include the time key in `partition_by`. Fixes the live row-duplication defect (Context). *Rejected:* auto-adding the time bucket to the grain (an implicit grain change the author never declared) and collapsing producer rows to a per-group pick (which value? arbitrary).
- **D10 — Regroup-substituted composites render at the combined stage.** A composite (arithmetic / scalar-call / CASE) measure whose leaves are all regroup placeholders after substitution is pre-aggregated: classify it to the combined stage and render over the attached values at the query grain, instead of the ROW-phase classification that raises "needs an aggregation". Mixed plain-aggregate + placeholder composites keep their current aggregate-phase path. *Rejected:* keeping the error (the ADDED requirement's flagship scenario demands the lift) and auto-wrapping in an identity transform (byte-noise, an implementation dodge).

## Risks / Trade-offs

- [Recursion meets an unanticipated shape] → D4 structural validation fails closed with a clean message; depth is bounded by strictly-decreasing grains.
- [Renderer gap under the hoistable context (nested `_cm_` + steps inside a producer)] → golden test for the acceptance shape; SQL Server + BigQuery emission paths exercised; scope-closure validation on all new emissions.
- [Byte-identity perturbation for existing single-grain shapes] → own-grain exclusion means `_plan_regroups` returns None inside single-grain producers exactly as today; full golden suite is the tripwire.
- [Silent wrong grain for nested transforms] → executed-value oracle chosen so union-grain evaluation and own-grain evaluation differ visibly (Codex F5).
- [Duplicate producers (same coarse aggregate, several roles)] → accepted (DEV-1824 design D10); stage-2 dedup.
- [D10 composite lift perturbs existing single-partitioned composites (plain+partitioned mix)] → that mix keeps its current path (only all-placeholder composites reclassify); locking tests + goldens are the tripwire.

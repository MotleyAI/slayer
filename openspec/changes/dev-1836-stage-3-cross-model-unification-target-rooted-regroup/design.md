# Design — DEV-1836 stage 3

## Context

See proposal.md — Why. Today: cross-model aggregates dispatch through `classify_isolation` (`engine/isolation.py:92`) into `CrossModelAggregatePlan` (forward CTE, re-rooted sub-plan, or filtered-local — `cross_model_planner.py`) and `RankedAggregatePlan` (`RANKED_TARGET`); the forward `_cm_` CTE groups only by dims exactly at the terminal target (`generator.py:5926` raises for intermediate hops; host-local dims CROSS-JOIN broadcast); the re-rooted path includes ANY reachable dim/filter with no arity check (`_key_reaches_from`), fanning the producer on 1:N hops — silent double counts. Join cardinality (DEV-1688) exists as metadata (`Join.cardinality`, `engine/cardinality.py`) but is query-time-unused; the Cube importer parses `relationship` and drops it (`cube/converter.py:669`); query-backed models carry no PK (`query_engine.py:2959`, DEV-1689). Stage 2 (DEV-1835, spec'd + TDD'd, unimplemented) is the assumed base: local `_wm_`/`_rk_` desugar onto the primitive, kernels producer-internal, plan-time dedup, effective grains. Hard constraints: goldens byte-identical except individually approved batches; executed values change only in the enumerated approved flips; fail-closed, never internal errors. Codex plan review produced 10 findings (F1–F10), all folded below.

## Goals / Non-Goals

**Goals:** one composition path for ALL measure families; the fan-out-safety doctrine (P1 grain / P2 metric independence / P3 attribution / P4 uniformity / P5 one mechanism) implemented as one safety predicate + one compilation rule; `classify_isolation` retired; the DEV-1837 matrix cells and the cross-model/intermediate-hop guards lifted with positive coverage.

**Non-Goals:** EXISTS semi-join filter pushdown (DEV-1840); distinct-entity attribution / symmetric aggregates (DEV-1841); dotted saved-measure references (DEV-1842); arity-driven inlining and order-wrap collapse (DEV-1738, re-scoped); stage-4 node discipline (DEV-1838); aggregate-over-attached nested attach (still fail-closed); short-form dim auto-routing; making `Join.cardinality` mandatory (rejected: forces a storage migration that must invent values — a `MANY_TO_ONE` default fill would be fail-open by stealth; `None`-as-unproven keeps honesty and option 3 gives it teeth).

## Decisions

- **D1 — Safety predicate as a new engine module, replacing reachability-only tests.** `provably_to_one(join) = covers_unique(target_pairs, target_model) or declared ∈ {m:1, 1:1}`; `safe_reachable(root, path)` = every hop provably ≤1, evaluated over EXISTING stored edges only (F1: inverting cardinality never synthesizes traversal; mirrored INNER edges already carry inverted cardinality from `join_sync`). Composite keys prove only under complete coverage (F6: assemble the full PK set before `is_key_set_unique`). Declarations are trusted at query time; validation flags detection-contradicted declarations (F5). `_key_reaches_from` and the prefix rules are deleted as value-path authorities; plain reachability survives only for grain-only resolution (spine dims/filters). *Rejected:* layering safety atop the old tests — two authorities that drift.
- **D2 — One compilation rule, run at every recursive planning level.** Per aggregate leaf: root R (source path terminal; query root when local; host for `grain="host"`), requested grain G (explicit `partition_by` else query dims), safe grain S (members of G safe-reachable from R in re-rooted coordinates). Explicit member ∉ S → hard error both modes (F4: enumerated as a class-(d) divergence; message names the remedy). Implicit: compute at S, broadcast over G∖S with metadata; strict errors. Inputs (source expr, args, kwargs, `Column.filter` refs) must each be safe-reachable from R; violation = hard error both modes (cannot be dropped — ambiguous read). Inline fast path (byte-identity): R = query root ∧ S = full grain ∧ inputs local-or-safe ∧ host grain fully safe → today's SQL. Everything else is a regroup producer rooted at R at grain S, attached row/combined per role. *Rejected:* keeping `classify_isolation` as a thin router — the rule IS the router.
- **D3 — Target-rooted producers via `reroot_value_key`; the `_cm_` builders die.** `cross_model_planner.py` + `CrossModelAggregatePlan` + `_render_cross_model_cte`/`_render_rerooted_cross_model_cte` + `_narrow_shared_grain_to_partition` + the D2 cross-model exclusion in `combined_partitioned_aggregates` are deleted; producer synthesis re-roots keys structurally (host-local → prepend host hop; on-path → strip prefix — the existing three rules). The filter decision table reincarnates as producer filter inheritance on the D7/D8 machinery: ROW conjuncts safe-reachable from R inherit re-rooted; reachable-but-unsafe or unreachable → excluded + dropped-filter warning (strict errors); AGGREGATE-phase routing unchanged. Forward-CTE broadcast semantics are preserved where already safe (terminal-target dims are zero-hop members of S). *Rejected:* keeping the plan classes producer-internal (the 1835 D2 pattern) — unlike `_wm_`/`_rk_` kernels, the `_cm_` builders duplicate exactly what producer synthesis + recursive render already do.
- **D4 — Nested attaches inside target-rooted producers are in scope; aggregate-over-attached stays excluded (F3).** A computed dimension whose expression columns are all safe-reachable from R joins S(A); its producer nests inside A's producer with keys re-rooted to R. `_validate_nested_producer_plan` relaxes from local-only to rooted-at-producer-root, keeps strict-subset grains (termination: grains strictly decrease) and extends the D8 complete-unique-key check to every nested attach. This is what flips the four matrix cells. *Rejected:* narrowing the rule to reject aggregate-bearing computed grain members — re-erects the guard the issue exists to lift.
- **D5 — DEV-1689 stamping is conditional on provable dedup (F2).** `create_model_from_query` stamps grain-column uniqueness (composite → `primary_key=True` on each member) only when the final stage aggregates or is dimension-only with `distinct_dimension_values=True`; the duplicate-preserving form stamps nothing. Negative test pinned.
- **D6 — Warnings ride the regroup IR (F7, F8).** Dropped-filter and broadcast events become fields on `RegroupAttachPlan` (nested plans included); the collector walks `regroup_attach_plans` recursively, replacing the `cross_model_aggregate_plans` walk. Identity: dropped filters keep `(location, filter text)`; broadcasts dedup by structural aggregate key, reported under the public measure name when directly selected, else canonical aggregate form + role; hidden/filter-only uses warn too; explicit-partition broadcasts never warn. New response warning `kind="broadcast"`; Python-warnings emission mirrors the dropped-filter one.
- **D7 — Total-routing invariant precedes the deletion (F9).** A post-discovery raise (not `assert` — must survive `-O`): every aggregate leaf has exactly one disposition (inline | producer substitution | explicit rejection), covering filter-only, order-only, ranked, windowed, host-grain, and nested leaves. Lands one commit before `classify_isolation` is removed, so the classifier's fail-closed backstops are replaced, not dropped.
- **D8 — Cube mapping is a closed table (F10).** `many_to_one`/`belongs_to` → MANY_TO_ONE; `one_to_many`/`has_many` → ONE_TO_MANY; `one_to_one`/`has_one` → ONE_TO_ONE; anything else → `None` + conversion-report warning. The parsed default `many_to_one` (Cube's own default) maps like an explicit value.
- **D9 — `strict` is a boolean on `SlayerQuery`** (REST/MCP pass-through), erroring on any silent-semantics event: implicit-grain broadcast or dropped producer filter. *Rejected:* an `on_unattributable` enum — three-valued surface for a two-valued decision; DEV-1841's opt-in is per-aggregate anyway.
- **D10 — Test-surface protocol (user-approved).** Four divergence classes: (a) byte-identical inline fast path — golden tripwire; (b) SQL-shape-only (migrated CTE bodies) — enumerated before/after, batch-approved, re-blessed, executed values pinned unchanged; (c) deliberate value changes (arity-unsafe grains → broadcast; unsafe inherited filters → dropped+warned) — enumerated with before/after values for approval; (d) new errors (unsafe inputs, unsafe explicit partition keys, strict) — enumerated. Fixture policy: audit join-declaring fixtures; declare target PKs where N:1 was intended (goldens hold), approve flips where genuinely 1:N.

## Risks / Trade-offs

- [Fail-closed flips values for fixtures/users with undeclared arity] → structural proof covers the common FK→PK case with zero declarations; fixture audit + enumerated class-(c) approvals; loud metadata means nothing changes silently; validation pressure names remedies.
- [Deleting `cross_model_planner.py` loses fought-for filter-routing behavior] → the decision table's cases become producer filter-inheritance tests first (TDD); the audit-vs-instruction distinction (`applied` vs `where`/`having`) is preserved on the regroup IR.
- [Producer-rendered `_cm_` bodies diverge widely from hand-built forward CTEs] → expected, class-(b); executed values pinned on both engines per shape; `assert_scope_closed` + no-placeholder-leak on every new emission.
- [Stage-2 interfaces drift before implementation] → implementation starts by merging then-current main and re-baselining (`validate --strict` re-run; the MODIFIED computed-dimensions deltas re-checked against the post-1835 corpus).
- [Discovery meets an unanticipated cross-model shape] → D7 invariant turns gaps into clean planner errors, never silent drops.
- [Broadcast surprises users who meant attribution] → warning text names DEV-1841's future opt-in remedy alongside the join-metadata remedies.

## Migration Plan

One PR on this branch, tests-first; ordered revertible commits: (0) safety predicate + D5 stamping + D8 Cube mapping + validation pressure (no query-behavior change) → (1) `_cm_` families onto target-rooted producers → (2) safe-grain flip + `strict` + broadcast metadata → (3) cross-model `_rk_`/partitioned/`window=`; delete `_narrow_shared_grain_to_partition` + the discovery exclusion → (4) guard lifts (matrix cells, computed-dim cross-model sources, intermediate hops) → (5) D7 invariant, then retire `classify_isolation`. Rollback = revert the PR (no storage migrations). Post-merge: archive; close DEV-1689; DEV-1738 already re-scoped by comment.
